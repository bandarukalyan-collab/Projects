## 2. Background & Context

The Greeting API currently returns only a default `"Hello, World!"` message. Users want to personalize the greeting by passing their name as a query parameter.

## 3. Scope

**In scope**: Add `name` query parameter to `GET /api/greeting` endpoint.
**Out of scope**: Locale support, authentication, template storage.

## 4. Functional Requirements

| # | Requirement | Source |
|---|------------|--------|
| FR-1 | API accepts optional `name` query parameter | JIRA description |
| FR-2 | When `name` is provided, greeting includes the name | JIRA AC-1 |
| FR-3 | When `name` is absent, default greeting is returned | JIRA AC-2 |
| FR-4 | Name must be 1-100 characters; return 400 if invalid | JIRA AC-3 |

## 5. Acceptance Criteria

- AC-1: `GET /api/greeting?name=Alice` returns `{"message": "Hello, Alice!"}`
- AC-2: `GET /api/greeting` (no name) returns `{"message": "Hello, World!"}`
- AC-3: `GET /api/greeting?name=` (empty) returns 400 with error message
